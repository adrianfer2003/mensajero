# Mensajero

App para el iPhone (o cualquier navegador) para escribirle a muchos leads seguidos: escoges la lista y el mensaje, y la app abre Mensajes con el texto ya personalizado para cada persona ("¡Hola Juan! Soy Adrian…"). Tú le das Enviar, vuelves a la app y ya está lista la siguiente.

**Abrir:** https://adrianfer2003.github.io/mensajero/

## Instalar en el iPhone
1. Abre el enlace en **Safari**.
2. Toca **Compartir** y luego **Agregar a inicio**.
3. Se abre como app, a pantalla completa, y funciona sin internet.

## Cómo se usa
1. **Leads**: importa el Excel (.xlsx) o CSV que te dan Facebook, el CRM o el concesionario, o pega una lista. La app reconoce las columnas de nombre, teléfono y auto, y no repite números que ya tienes.
2. **Plantillas**: escribe el mensaje una vez con los datos que se llenan solos: primer nombre, nombre completo, auto de interés, tu nombre y el concesionario.
3. **Enviar**: escoge a quién (por lista y por estado) y el mensaje. Para cada lead toca **Enviar a…**, se abre Mensajes, le das enviar y vuelves. Puedes saltar a alguien, marcarlo como "No contactar" o cambiarle el mensaje solo a esa persona.

## Reglas incluidas
- Avisa si mandas antes de las 8 am o después de las 8 pm (ley de Florida).
- Por defecto no incluye a quien ya le escribiste en las últimas 24 horas.
- Quien esté marcado "No contactar" nunca sale en los envíos.
- Puedes agregar al final "Responde STOP para no recibir más mensajes" (o en inglés).

## Tus datos
Los leads se guardan **solo en tu teléfono**, no en internet ni en este repositorio. En Ajustes puedes guardar un respaldo, restaurarlo en otro teléfono o exportar los leads a CSV.

Hecho con HTML, CSS y JavaScript, sin dependencias.
